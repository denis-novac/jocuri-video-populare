## 📖 Despre proiect

**Jocuri Video Populare** este un site web informativ construit exclusiv cu HTML, CSS și JavaScript, dedicat prezentării celor mai populare și influente jocuri video. Proiectul explorează industria gaming-ului, genurile de jocuri, topuri și galerii vizuale, oferind o resursă educațională accesibilă oricui.

---

## 🗂️ Structura proiectului

```
jocuri-video-populare/
│
├── index.html                  # Pagina principală (slideshow + prezentare generală)
├── genuri_si_tipuri.html       # Genuri și tipuri de jocuri video
├── topuri.html                 # Clasament cu cele mai populare jocuri
├── galerie.html                # Galerie foto din jocuri populare
├── despre.html                 # Informații despre proiect
│
├── game_pages/                 # Pagini dedicate fiecărui joc din top
├── images/                     # Toate imaginile utilizate în site
└── style.css                   # Fișier global de stilizare
```

---

## 📄 Pagini principale

| Pagină | Fișier | Descriere |
|--------|--------|-----------|
| **Acasă** | `index.html` | Slideshow vizual + prezentare generală a industriei gaming |
| **Genuri & Tipuri** | `genuri_si_tipuri.html` | Descrierea genurilor (Action, FPS, RPG, Racing etc.) cu exemple |

| **Despre** | `despre.html` | Scopul proiectului, tehnologii utilizate, funcționalități |

## 🚀 Cum rulezi proiectul

1. **Clonează repository-ul:**
   ```bash
   git clone https://github.com/denis-novac/jocuri-video-populare.git
   cd jocuri-video-populare
   ```

2. **Deschide în browser:**
   - Direct: deschide `index.html` în orice browser modern
   - Cu Live Server (VSCode): click dreapta pe `index.html` → *Open with Live Server*

> Nu este necesară nicio instalare sau configurare suplimentară.
> Dacă dorești să adaugi o pagină nouă, te rugăm să urmezi modelul celor existente (structura HTML + style.css), să adaugi resursele în folderul images/ și să trimiți un Pull Request cu modificările tale. Orice îmbunătățire este binevenită!
